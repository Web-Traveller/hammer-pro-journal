Windows installation

One download. A few clicks.

Because Hammer Pro is independently distributed, Windows SmartScreen may display a warning when you first download the installer.

The warning is related to application reputation and signing, not a Hammer Pro login requirement.

01

Keep the download

In Microsoft Edge, open the download menu and choose Keep.

02

Choose Keep anyway

If Edge displays a download warning, select Keep anyway.

03

Run the installer

Open the downloaded file. If SmartScreen appears, select More info and then Run anyway.

04

Import your executions

Open Hammer Pro and bring in your broker's exported trade history.
