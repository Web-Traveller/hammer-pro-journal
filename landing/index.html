Installing for the first time?

Windows SmartScreen Note

Because Hammer Pro Journal is an indie desktop application without a $500/year enterprise corporate certificate, Microsoft Edge and Windows Defender SmartScreen may display a generic "Not commonly downloaded" prompt. The app is 100% clean, open-source-backed, and local-first.

1
In Microsoft Edge
Hover over download, click ... (Options) → Select Keep → Click Keep anyway.
2
In Windows Defender
When the blue prompt appears, click More info → Click Run anyway.
